One emoji that stands for our AI agent: 🕵️ (detective).

Our agent hunts free garapan around the clock — it scans, verifies
on-chain, and strikes fast. The detective is that hunter-verifier in a
single glyph: readable at a glance even at small size, specific to how
the agent works, and far from the obvious robot or smiley.

## How it works

`main.py` writes the single emoji to `/output/entry.txt` (UTF-8, no
trailing newline, no extra text). Run it with:

```sh
python3 main.py
```
